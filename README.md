# Mason Bee Typographic Plates

A set of 25 original typographic field plates about solitary bees and mason bees, published by Lanternbay Studio under the Stem & Mud sub-brand.

Each plate pairs a short original slogan with procedural line art and typography. The designs are rendered in code (Python and SVG), not drawn in a raster editor and not produced by a generative image model.

This repository contains the render scripts, SIL Open Font License fonts used on the plates, and a few small previews. It does not include full-resolution PNG masters. Print-ready files are released as a paid-what-you-want pack on itch.io (coming 2026-11-26).

## AI Assisted

These scripts were written with AI assistance. The designs themselves are rendered by code, using original typography, OFL-licensed fonts, and line art drawn as SVG in the scripts. They were not generated by an image model.

## How to render

You need Python 3.10 or later. Plates 16–25 also need a system Cairo library (the `cairosvg` package depends on it).

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python scripts/render_designs.py      # plates 01–15
python scripts/render_16_20.py        # plates 16–20
python scripts/render_21_25.py        # plates 21–25
```

Outputs are written to `output/` (dark ink, for light paper or light garments) and `output/dark/` (light ink, for dark garments). Each master is a 5000 × 5500 px transparent RGBA PNG.
